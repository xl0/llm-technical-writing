# LLM technical writing

A quick test of models' ability to explain technical topics.

## Prompts

- [Introduction to Rust](rust-intro/): a condensed introduction for experienced
  C, Python, and TypeScript programmers.

## Read in a browser

[Open the reading room](https://xl0.github.io/llm-technical-writing/rust-intro/),
or open [`rust-intro/index.html`](rust-intro/index.html) locally in your browser.
The standalone reader includes all eight frozen introductions, syntax-highlighted
code, a section outline, and expandable diagrams. Model names are visible;
no model grades appear alongside the writing. Works offline.
